# Contrato I8 → A1

## Objetivo

Definir o formato da comunicação entre o componente
I8 (Inferência) e A1 (Aplicação).

Isso permite que os componentes sejam desenvolvidos
independentemente.

# Evento: PieceAnalyzed

## Exemplo

```json
{
  "message_type": "event",
  "schema": "ods.ver1.i8_piece_analyzed",
  "schema_version": "1.0",
  "producer": "I8",
  "published_at": "2026-09-23T10:00:00.000Z",

  "payload": {
    "piece_id": "P000123",

    "classification": {
      "id": "AMASSADO"
    },

    "confidence": 0.91,
    "similarity": 0.28,

    "evidence": {
      "image_url": "/frontend/assets/images/mock-piece-defective.png"
    }
  }
}
```

O I8 publica apenas o identificador da classificação. Nome, descrição,
severidade e consequência são resolvidos pelo A1 a partir de
`shared/defect-categories.json`, fonte única da taxonomia. O resultado da
triagem é publicado separadamente por A1 no evento
`ods.ver1.a1_triage_result`; portanto, o I8 não publica `APPROVED`, `REJECTED`
ou `REVIEW`.
